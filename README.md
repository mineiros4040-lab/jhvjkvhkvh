# AF Informática SaaS

MVP profissional para gestão de assistência técnica.

- Dashboard
- Cadastro de clientes
- Cadastro de OS
- Número automático AF-YYYY-000001
- Placa de vídeo, placa-mãe, notebook, celular e desktop
- Marca, modelo, memória, serial/IMEI, defeito, estado físico, acessórios e valor
- Busca, filtros, status e impressão
- Relatórios
- Responsivo
- Persistência local para MVP

## Executar
npm install
npm run dev
